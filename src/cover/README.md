# Making the Cover

Go to the [Cover Calculator]() and enter the following:

* PDF Page Count
* Binding type: Paperback
* Interior type: B & W
* Paper type: White paper
* Reading direction: Left to Right
* Measurement units: Inches
* Interior Trim Size: 7.5 x 9.25

Then Download Template.

* Open the `.svg` and the template PDF in Inkscape.
* Select the proper layer in the SVG.
* Copy the PDF data into it.
* Set the top and left of the PDF data to 0,0.
* Make sure the rulers are aligned with the template.
* Resize the jigs to the rules.
* Center the content appropriately on the jigs.
* Lock everything.
* Turn off unnecessary layers.
* Export as PDF.
  * Rasterize effects.
  * Convert font to path.
